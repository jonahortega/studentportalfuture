# AUP - American University of Paris App

A comprehensive student portal and activities app for American University of Paris.

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)
